# 第一部分 · v2 变更评审

## 1.1 一句话总结

**v1 的三大硬缺口（G1/G2/G3）在 v2 里全部被填掉了，而且元素系统是推倒重写而不是打补丁——现在的版本已经可以直接开工做白盒。**

## 1.2 逐条对照

| 缺口 | v1 状态 | v2 状态 | 结论 |
|---|---|---|---|
| **G1** 元素反应触发条件不明 | 只有 3 条，且"使用法术时"可歧义成 3 种解释 | **重写为 6 条定向反应 + 3 条同元素规则**，明确是"法术 × 地形" | ✅ **完全解决** |
| **G2** 地形→玩家增益矩阵为空 | 唯一样例是"木属性玩家在水池旁获得 XXX" | **整条设计被删除**，改为"地形拥有元素属性，玩家用不同类型法术与地形交互" | ✅ **风险消失**（不是填补，是砍掉） |
| **G3** 关卡生成规则自相矛盾 | "BOSS 房在路尽头" vs "特殊房只能连小怪房" 冲突 | 删除"路尽头"约束，补"类似《以撒的结合》"+ BOSS 房传送门 | ✅ **基本解决** |
| **G4-a** 法术槽 6 个 vs 按键 5 个 | 自相矛盾 | 改为"六个按键（QWEASD）" | ✅ 已修正（QWEASD 本就是 6 个键） |
| **G4-b** "法术对象池"含义不明 | "法术拥有一个对象池" | **该句被删除** | ✅ 歧义消失 |
| **G4-c** "充能"与"法力"关系不清 | 充能主动 + 地形充能 + 法力，三套资源混着说 | 改为"可复用主动消耗法力"，法力**仅**由拾取元素恢复 | ✅ 简化为单一资源 |
| **G4-d** 单局失败条件未定义 | 无 | 补"血量归零后单局游戏失败，进入结算" | ✅ 已补 |

## 1.3 v2 新增的内容

**元素系统重写（核心增量）**

新规则三条：
1. **每个地形初始可发生三次元素反应（可被补充）** —— 地形是有耐久/次数的消耗品
2. **同元素法术 × 同元素地形 → 目标地形反应次数 +1** —— 自洽的回充机制
3. **单次法术与同一地形每 60 帧最多产生一次反应** —— 防抖/防刷

新的 3×3 反应矩阵（行 = 法术元素，列 = 地形元素）：

| 法术＼地形 | 水地形 | 火地形 | 木地形 |
|---|---|---|---|
| **水法术** | 地形 +1 次数 | **穿过**地形，伤害**翻倍**（火炬树桩） | 生成**腐烂区域**，减速区域内单位 |
| **火法术** | 生成**蒸汽区域**，持续伤害 | 地形 +1 次数 | 以地形为中心**爆炸**，一次性大量伤害 |
| **木法术** | 生成**回血区域**，缓慢回血 | **穿过**地形，命中者**灼伤** 5% maxHP/s（BOSS 1%） | 地形 +1 次数 |

> 对比 v1：v1 只有"水火→蒸汽、水木→回血、木火→爆炸"三条，且把"木火"写成了**木法术撞火法术**（法术对撞），v2 统一成**法术撞地形**。**这是一个重要的实现简化**——不需要做法术弹体之间的碰撞检测（宽相位），只需要做弹体 vs 地形网格查询。

**新增房间行为定义**

- 商店房 → 生成商店
- 法术房 → 随机生成一个**已解锁**的法术
- 宝箱房 → 随机生成一个**当前道具池**的道具
- BOSS 房 → 击败 BOSS 后生成**传送门**，进传送门到下一层

**新增/删除的字段**

- ➕ 怪物编辑器增加 **掉落物权重**
- ➕ "掉落物权重由怪物种类决定"
- ➕ 修正器列表增加 **地形生成**（生成地形，可与其他法术进行元素反应）
- ➕ 玩家属性补充说明
- ➖ 删除 **事件房**（v1 房间列表有，v2 没有）
- ➖ 删除"地形旁缓慢充能 / 吸干地形充能"机制
- ➖ 删除"Boss 房一定在一条道路的尽头"
- ➖ 删除"法术拥有一个对象池"

## 1.4 v2 之后仍然存在的缺口

这些不是"数值没填"，而是**规则本身还有洞**，数值填不上：

| # | 缺口 | 影响 | 白盒临时假设 |
|---|---|---|---|
| **A1** | **法术的元素从哪来？** v2 说"地形拥有元素属性"，但没说法术的元素由谁决定 | ⚠️ **最关键** | 玩家有一个"当前元素"（祭祀场选的），发射的法术继承该元素；法术自带固有元素时以固有为准 |
| **A2** | "反应次数可被补充"——除同元素外还有别的补充方式吗？ | 中 | 白盒只实装同元素回充 |
| **A3** | 地形反应次数**耗尽后**，地形变成什么？消失？变普通？ | 中 | 地形保留，但不再触发反应（视觉变灰） |
| **A4** | 穿透类反应（水/火、木/火）是否**消耗**地形次数？ | 中 | 消耗，与其他反应一致 |
| **A5** | 区域效果（蒸汽/腐烂/回血）是否也吃"每 60 帧一次"的限制？ | 低 | 区域只在生成时判定一次，之后按 tick 结算 |
| **A6** | 区域重叠如何结算？（两块蒸汽叠加） | 中 | 各自独立 tick，伤害分别结算（会叠） |
| **A7** | 灼伤能否叠加/刷新？ | 低 | 只刷新持续时间，不叠层 |
| **A8** | 回血区域"区域内所有单位"——**包括怪物吗？** | ⚠️ 高 | **按字面包括怪物**（会变成"奶怪"设计，可能是特性也可能是陷阱，需确认） |
| **A9** | 每层房间数量区间、房间网格尺寸 | 中 | 见下表，全部为占位 |
| **A10** | 幸运值具体影响什么 | 低 | 白盒只影响 1 个法术的击退距离 |
| **A11** | 商店定价、宝箱道具池构成 | 低 | 见下表 |
| **A12** | 六个槽如何容纳"修正器"？修正器占不占槽？ | ⚠️ **高** | 槽位视为**有序队列**，修正器作用于其后第一个法术卡（《noita》式） |
| **A13** | 第 5 层 BOSS 之后是什么（通关条件） | 低 | 白盒不做 5 层 |

## 2.2 地形元素反应（对应 v2 元素系统）

**地形侧参数**

| 参数 | 值 | 说明 |
|---|---|---|
| 初始反应次数 | **3** | ⚠️ **改为按"整块地形"共享**，不再每格独立 |

| 法术＼地形 | 水地形 | 火地形 | 木地形 |
|---|---|---|---|
| **水法术** | 地形 +1 次 | **穿透**：弹体继续飞行不消失，`伤害 ×2` | **腐烂区域**<br>半径 2.5 / 存续 5 s<br>区域内单位 `移速 ×0.5` |
| **火法术** | **蒸汽区域**<br>半径 3.0 / 存续 6 s<br>`8 伤害 / 0.5 s` 一跳 | 地形 +1 次 | **爆炸**<br>半径 2.5 / 瞬时<br>`40 一次性伤害` + 击退 1.5 |
| **木法术** | **回血区域**<br>半径 2.5 / 存续 6 s<br>`5 HP / 0.5 s` 一跳 | **穿透**：弹体继续飞行<br>命中者获得**灼伤**<br>`5% 最大生命 / 秒`（BOSS `1%`）<br>持续 **4 s**，只刷新不叠层 | 地形 +1 次 |

**区域效果通用规则（白盒约定）**

- tick 间隔统一 **0.5 s**（30 帧）
- 区域对**玩家、怪物、BOSS 全部生效**（含回血区域 —— 见 A8，需确认）
- 区域重叠各自独立结算
- 区域生成时一次性消耗该地形 **1 次**反应次数
- 穿透类反应同样消耗 **1 次**
